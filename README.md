## Reproduce the Workbook

The workbook uses Tableau's **Sample - Superstore** Excel dataset.

1. Download **Superstore Sales** from the official [Tableau Public sample-data page](https://public.tableau.com/app/learn/sample-data).
2. Create a `data` folder beside `Tableau_Sales_Profit_Analysis.twb`.
3. Rename the downloaded workbook to `Sample - Superstore.xls` and place it at:
   `data/Sample - Superstore.xls`
4. Open `Tableau_Sales_Profit_Analysis.twb` in Tableau Desktop or Tableau Public.
5. If Tableau asks for the source, select the Excel file above and choose the `Orders` worksheet.

The published workbook now uses a repository-relative source path instead of a local Windows account path. See `data/README.md` for the data-source note.

## Business Insights

- The West region generated the highest sales and profit.
- Technology led product categories in both sales and profit.
- Furniture had substantially lower profit than Technology and Office Supplies.
- Monthly sales fluctuated significantly, highlighting the importance of monitoring sales trends.
