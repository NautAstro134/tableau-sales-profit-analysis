# Tableau data dependency

Download **Superstore Sales** from Tableau's official sample-data page:

https://public.tableau.com/app/learn/sample-data

Save the Excel workbook here as:

`Sample - Superstore.xls`

Expected path from the repository root:

`data/Sample - Superstore.xls`

The dataset is not redistributed here. The Tableau workbook references this relative path and uses the `Orders` worksheet.
